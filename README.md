💬 Customer Feedback Analyzer

A Machine Learning-based web application that analyzes customer reviews and classifies them into Positive, Neutral, or Negative sentiment using Natural Language Processing (NLP).

🚀 Features

- Analyze a single customer review.
- Upload a CSV file and analyze multiple reviews at once.
- Sentiment prediction with confidence score.
- Topic analysis (Delivery, Size, Quality, Style, Price).
- Sentiment distribution using bar chart and donut chart.
- Download analyzed results as a CSV file.

🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- Matplotlib
- NLTK

🤖 Machine Learning Model

- TF-IDF Vectorizer
- Logistic Regression
- LDA Topic Modeling

📂 Dataset

Women's Clothing E-Commerce Reviews Dataset ("Clothing_Reviews.csv").

▶️ Run the Project

pip install -r requirements.txt
streamlit run app.py

📊 Project Output

The application predicts customer sentiment, identifies the main feedback topic, visualizes sentiment distribution, and allows users to download the analyzed reviews.
